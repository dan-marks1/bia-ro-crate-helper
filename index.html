Set up and run the inventory script
  1. To install it on Codon, copy the terminal setup below and paste it at the Codon shell prompt. This creates ~/bia_crate_inventory.py.
  2. Enter the Codon directory below, copy the generated command, and paste it at the Codon shell prompt. It runs from your home directory and saves the report there.
  3. Copy the generated scp command into a terminal on your Mac to bring the report back, then select it above.
